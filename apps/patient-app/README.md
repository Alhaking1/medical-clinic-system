# Patient App (تطبيق المريض)

تطبيق أندرويد موجه للمرضى يتيح البحث عن الأطباء، حجز المواعيد والكشوفات (عادية / مقعد ذهبي VIP)، وتتبع الطابور الحي بالدقيقة، بالإضافة لمساعد سريري ذكي.

## 🛠️ متطلبات التشغيل
* Android Studio (Koala / Ladybug أو أحدث)
* JDK 17
* Android SDK 34 (أو أحدث)

## 📱 خطوات الفتح والتشغيل
1. افتح Android Studio.
2. اضغط **File -> Open**.
3. اختر مجلد `apps/patient-app`.
4. اضغط **Sync Project with Gradle Files**.
5. قم بتحديد المحاكي أو جهاز حقيقي واضغط **Run**.

## 🌐 ضبط رابط السيرفر
يمكن تعديل رابط الاتصال بالسيرفر في ملف `Constants.kt` أو `ApiService.kt`:
* للمحاكي: `http://10.0.2.2:8080/api`
* للجهاز الحقيقي عبر الـ Wi-Fi: `http://[IP-Address]:8080/api`
