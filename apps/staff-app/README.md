# Staff App (تطبيق الكادر الطبي والسكرتيرة)

تطبيق أندرويد موجه للأطباء وموظفي الاستقبال (السكرتارية) لتنظيم الطوابير الحية، الكشف على المرضى، تحرير الروشتات الطبية، وتأكيد الحضور عبر الـ QR و NFC.

## 🛠️ متطلبات التشغيل
* Android Studio (Koala / Ladybug أو أحدث)
* JDK 17
* Android SDK 34 (أو أحدث)

## 📱 خطوات الفتح والتشغيل
1. افتح Android Studio.
2. اضغط **File -> Open**.
3. اختر مجلد `apps/staff-app`.
4. اضغط **Sync Project with Gradle Files**.
5. قم بتحديد المحاكي أو جهاز حقيقي واضغط **Run**.
