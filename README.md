# Medical Clinic System (نظام إدارة العيادات الطبية والانتظار الذكي)

نظام متكامل وشامل لإدارة العيادات، الطابور اللحظي، حجز المواعيد، وتسهيل التواصل بين المرضى والأطباء وموظفي الاستقبال.

---

## 🏗️ هيكلية المشروع (Project Architecture)

المستودع مقسم بشكل مستقل لمنع أي تداخل بين أعضاء الفريق:

```text
medical-clinic-system/
│
├── 📁 backend/                # السيرفر، قواعد البيانات، والـ APIs (Node.js / Express / SQLite)
│   ├── src/                  # المسارات والخدمات والتحقق
│   ├── database/             # ملفات ومخططات قاعدة البيانات
│   └── README.md             # دليل تشغيل السيرفر
│
├── 📁 apps/
│   ├── 📁 patient-app/       # تطبيق المريض (Android Kotlin)
│   │   ├── app/              # واجهات وكود المريض، والمساعد الذكي
│   │   └── README.md         # دليل تشغيل تطبيق المريض
│   │
│   └── 📁 staff-app/         # تطبيق الكادر الطبي (الطبيب والسكرتيرة - Android Kotlin)
│       ├── app/              # إدارة الطوابير، الكشوفات، والروشتات
│       └── README.md         # دليل تشغيل تطبيق الكادر
│
└── 📁 docs/                   # التوثيق والشروحات
```

## 🚀 دليل البدء السريع لأعضاء الفريق

### 1. إعداد السيرفر (Backend)
إذا كنت مسؤولاً عن الباك إند أو تريد تشغيل السيرفر محلياً:
```bash
cd backend
npm install
npm run dev # أو npm start
```
* يعمل السيرفر افتراضياً على المنفذ: `http://localhost:8080`
* يمكنك الاطلاع على تفاصيل المسارات والـ APIs في `backend/README.md`.

---

### 2. تشغيل تطبيقات الأندرويد (Mobile Apps)
* **تطبيق المريض (`apps/patient-app`):**
  1. افتح برنامج **Android Studio**.
  2. اختر **Open** ثم حدد المسار: `apps/patient-app`.
  3. انتظر اكتمال مزامنة Gradle، ثم اضغط **Run**.
* **تطبيق الكادر الطبي (`apps/staff-app`):**
  1. افتح نافذة جديدة في **Android Studio**.
  2. اختر **Open** ثم حدد المسار: `apps/staff-app`.
  3. شغّل التطبيق لتجربة حسابات الأطباء والسكرتارية.

## 👥 قواعد المساهمة للفريق (Git Workflow)
1. قم بإنشاء فرع جديد (Branch) لكل ميزة تعمل عليها:

   ```bash
   git checkout -b feature/your-feature-name
   ```
2. احرص على كتابة Commit واضح يوضح ما تم إنجازه.
3. ارفع تعديلاتك واطلب مراجعة (Pull Request).
